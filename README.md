# ♟️ Chess Game (C++ | OOP)

A fully functional console-based Chess Game developed in C++, built using core 
Object-Oriented Programming concepts to simulate real chess rules and gameplay.

## 🎯 Features
- Complete chessboard representation and piece movement logic
- Individual classes for each piece type (Pawn, Rook, Knight, Bishop, Queen, King)
- Move validation according to standard chess rules
- Turn-based gameplay for two players
- Console-based interactive interface

## 🛠️ Concepts Used
- **Inheritance** – Base `Piece` class extended by specific piece types
- **Polymorphism** – Virtual functions for move validation of each piece
- **Encapsulation** – Board and piece data protected within classes
- **Abstraction** – Simplified interface for game logic

## 💻 Tech Stack
- Language: C++
- Paradigm: Object-Oriented Programming

## 🚀 How to Run
```bash
g++ main.cpp -o chess
./chess
```

## 📚 Project Background
Developed as part of the Object-Oriented Programming course at NUCES, 
applying real-world class design and inheritance hierarchies to a 
practical, rule-based game system.
